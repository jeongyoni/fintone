# FinTone — 주가 예측 및 분석 프로젝트

> 2025.06 ~ 2025.07

뉴스 감정 분석과 외국인 수급 데이터를 활용한 주가 예측 및 포트폴리오 리밸런싱 시스템

## 프로젝트 구조

```
├── 뉴스수집/          # 뉴스 크롤링 및 전처리 (네이버, 구글)
├── 크롤링-전처리/     # 주가 및 외국인 수급 데이터 수집·전처리
├── 모델링/            # BERT 감정 분석, 모델 비교, 리밸런싱 ETF
├── 시각화/            # 주가 데이터 분석 시각화
├── 웹구현/fintone/    # 웹 대시보드 (HTML/CSS)
└── 주가-외국인/       # 외국인 수급 분석
```

## 주요 기능

- **뉴스 감정 분석** — BERT 모델 기반 뉴스 감정 점수화
- **주가 예측 모델** — 감정 + 수급 데이터 결합 예측
- **포트폴리오 리밸런싱** — ETF 기반 자동 리밸런싱 전략
- **실시간 급등 확률** — 실시간 뉴스 기반 급등 종목 탐지
- **웹 시뮬레이터** — 투자 전략 백테스팅 웹 인터페이스

## 기술 스택

- Python, Jupyter Notebook
- BERT (KoBERT / FinBERT)
- Pandas, Scikit-learn, PyTorch
- HTML / CSS (웹 대시보드)
